# iPUB — İndir

PDF kitaplarınızı Kindle ve diğer e-okuyucular için EPUB'a dönüştüren **iPUB**'un macOS ve Windows kurulum dosyaları burada yayımlanır.

**[Son sürümü indir →](https://github.com/Ulas-Yilmaz/iPUB-releases/releases/latest)**

- **macOS:** `iPUB-x.y.z-universal.dmg` (Apple Silicon ve Intel)
- **Windows:** `iPUB-Setup-x.y.z.exe` (64 bit)

Kurulum ve ilk açılış adımları her sürümün notlarında yer alır. Uygulama kurulduktan sonra yeni sürümleri kendisi denetler.
